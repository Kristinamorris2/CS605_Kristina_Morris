# Simple Calculator

## Description

This simple calculator can perform arithmetic functions such as addition, subtraction, multiplication, and division.

## How to Use the Calculator

Enter two numbers you wish to calculate. Each value should be entered as a separate input.

The operations are labeled as follows:

- 1 = Addition
- 2 = Subtraction
- 3 = Multiplication
- 4 = Division

After entering the two numbers, enter a number from 1-4 to select the operation you would like to perform.

After the calculation is performed, Python will print the result and ask if you wish to perform another calculation.

If you enter "yes", you can perform another calculation.

If you enter "no", the program will print "Goodbye!" and the calculator will stop.
